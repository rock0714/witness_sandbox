# The Witness パズル考察サンドボックス (Witness Sandbox)

「The Witness」のゲーム画面をキャプチャし、斜めに傾いたパズル盤面をOpenCVの透視投影変換（Perspective Warp）で真正面の真四角画像に補正した上で、仮想グリッド上で一筆書きやブロック塗りつぶしによる考察を行えるサポートツールです。

---

## 🌟 主な機能

1. **画面キャプチャ & 画像読み込み**
   - **グローバルホットキー (F4)** または UI ボタンでいつでも画面を瞬時にキャプチャ。
   - キャプチャ時は本アプリが自動で非表示になり、F4を押した時点で前面にあったウィンドウ（ゲーム画面）のみを撮影（取得できない場合は全画面にフォールバック）。
   - ローカルの画像ファイル読み込みや、テスト用の「サンプル盤面読み込み」も搭載。

2. **パース補正（透視投影変換） & 正方形(1:1)比率保持**
   - 斜めに見えているパズル盤面の「四隅（4点）」をマウスクリックで指定。
   - 点のドラッグによる微調整、右クリックによる点の削除が可能。
   - **比率選択**: 「正方形 (1:1)」「マス目比 (列:行)」「元画像比」から選択可能。パズル盤面が正方形や正方形マス目の場合でも、遠近法の歪みを解消して美しい 1:1 比率で正面化。
   - **マス目自動検知（画像解析）**: 「🔍 マス目検知」ボタンを押すか補正を実行すると、盤面のグリッド線から列数・行数・マージンを自動推定して反映。

3. **仮想グリッドの重畳 & 直感的なスライダー調整**
   - 補正後画像の上に、任意のサイズ（行数・列数をスライダーで1〜20まで直感的に変更）のグリッドを生成。
   - マス目自動検知により、補正時に行・列・マージンが自動設定されます。
   - 外枠マージン調整（0〜30%）で手動微調整も可能。
   - **枠調整ツール**: 外枠の角・辺をドラッグしてサイズ変更、内側をドラッグして全体を移動できるため、四隅がずれてもマス目にぴったり合わせられます。

4. **線塗り（辺のトグル & 1操作1方向ドラッグ制御）**
   - グリッドの線（辺）をクリックするとその線が塗られ、塗り済みの線をもう一度クリックすると消えます。
   - ドラッグ操作時は、**1つの交点からは1操作で1方向にしか線が伸びない**よう制御されており、少し触れただけで勝手に別の方向へ線が伸びてしまうことを防ぎます。マウスを戻すと巻き戻しも可能。
   - **思考用3本目描画**: 1操作ごとの制御であるため、別の操作（クリックやドラッグ）を行えば同一交点に3本目・4本目の線（T字路・分岐・合流など）を自由に引くことができ、柔軟なパズル考察が可能です。
   - ドラッグでなぞると連続で塗り/消去（最初にクリックした線が塗り済みなら消去モード）。右クリックで即消去。
   - 鮮やかなネオンカラーのライン表示。

5. **半透明ブロック塗りつぶし**
   - マス目（セル）をクリックすると、半透明カラーで塗りつぶし。
   - 背景の記号（四角や星など）が透けて見えるため、テトリスブロックやエリア分けの考察に最適。
   - 同じマスをクリックすると消去（トグル操作）、ドラッグで連続塗りも可能。

6. **ツール & 補助機能**
   - **モード切替**: 線塗り / マス目塗り / 自由手書き / 消しゴム
   - **消しゴムツール**: クリックやなぞり（ドラッグ）で、塗った線、マス目塗り、自由手書きメモをまとめて消去可能。
   - **カラーパレット**: Witness風オレンジ、イエロー、シアン、グリーン、ピンク、ホワイト、カスタム色
   - **編集操作**: 1つ戻る（Undo: `Ctrl+Z`）、全消去（Clear）、考察画像の保存（PNG/JPEG）
   - **常に最前面表示（TopMost）**: ゲーム画面の手前にウィンドウを固定したまま考察可能。

## 💻 動作環境と制限事項

本アプリは **Windows 環境での動作を前提** として開発されています。

- グローバルホットキー（F4）によるキャプチャ機能や前面ウィンドウの取得には、Windows API（`ctypes.windll.user32`）を使用しています。
- そのため、Mac や Linux 環境で実行した場合、一部のキャプチャ機能が動作しない、またはエラーになる可能性があります。（画像ファイルの読み込みやパース補正、サンドボックス機能自体はクロスプラットフォームで動作します）

## 🛠️ インストールと実行方法

本プロジェクトは Python で記述されています。依存関係の管理と実行には、高速な Python パッケージマネージャである [uv](https://github.com/astral-sh/uv) の使用を推奨します。

### 1. `uv` を使用した起動（推奨）

`uv` をインストール済みであれば、以下のコマンドを実行するだけで仮想環境の構築と依存ライブラリのインストール、アプリの起動がすべて自動で行われます。

```bash
# リポジトリのクローン
git clone https://github.com/rock0714/witness_sandbox.git
cd witness_sandbox

# uv を使って起動
uv run witness_sandbox.py
```

### 2. 標準の `pip` を使用した起動

標準的な Python 環境を使用する場合は、以下の手順を実行してください。

```bash
# リポジトリのクローン
git clone https://github.com/rock0714/witness_sandbox.git
cd witness_sandbox

# パッケージのインストール
pip install -r requirements.txt

# 起動
python witness_sandbox.py
```

> [!NOTE]
> `keyboard` ライブラリによるグローバルホットキー（F4）は、他のアプリがフォーカスされていても動作します。環境によっては管理者権限が必要な場合がありますが、UI上の「📷 画面キャプチャ」ボタンでも同様にキャプチャ可能です。

## 📖 操作手順の流れ

### ステップ 1: ゲーム画面のキャプチャまたは読み込み
- ゲーム「The Witness」のパズル画面を表示した状態で、**F4キー** を押すか、上部バーの **「📷 画面キャプチャ (F4)」** をクリックします。
- または、**「📁 画像を開く...」** や **「🧩 サンプルパズル読込」** で画像をロードします。

### ステップ 2: パズル盤面の四隅を指定して補正
1. 画面上のパズルパネルの四隅（左上、右上、右下、左下など任意の順）をクリックして4つの点（P1〜P4）を打ちます。
   - 点をドラッグすると微調整できます。
   - 点を右クリックするとその点を削除できます。
   - 「↺ 四隅リセット」で全クリアできます。
2. 4点が揃うと **「➡️ 補正してサンドボックスへ」** ボタンが有効になります。クリックすると真正面の画像へ補正されてサンドボックス画面に切り替わります。

### ステップ 3: サンドボックスでの考察
- **グリッドの調整**:
  - 上部コントロールバーの「行」「列」を変更し、パズルのマス数に合わせます（例: 4x4, 3x6など）。
  - 「マージン」スライダーで外枠の余白を調整し、盤面のラインとぴったり重ねます。
- **一筆書きスナップ**:
  - 格子点の近くをクリック＆ドラッグすると、カチッと吸着しながら線が引けます。
  - ドラッグ中に戻ると線が巻き戻ります。
- **マス目塗り**:
  - 「マス目塗り」ツールを選び、マスをクリックすると半透明で色塗りができます。
- **操作の取り消し・保存**:
  - `Ctrl+Z` または「↩ 1つ戻る」でUndo。
  - 「💾 保存」で考察結果を画像ファイルとして保存できます。
- **最前面表示**:
  - 右上の「常に最前面表示 (TopMost)」にチェックを入れると、ゲームを見ながら手前で考察できます。
